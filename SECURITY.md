# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

We provide security updates and patches for the current release on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability in InkBoard, please do NOT file a public issue.

Instead, please report security vulnerabilities directly to the maintainers:
- **Email**: `ellaboevans@gmail.com`
- **Subject**: `[SECURITY] Vulnerability Report in InkBoard`

Please include in your report:
- A description of the vulnerability and its potential impact.
- Clear steps or a proof of concept demonstrating how to reproduce the issue.
- Any relevant logs, versions, or configurations.

We will acknowledge receipt of your report within 48 hours and coordinate a timely fix and disclosure plan.
