# Getting Support for InkBoard

Thank you for using InkBoard! Here are the best ways to get assistance:

## Documentation

- **Getting Started & Architecture**: Check `README.md` and `docs/ARCHITECTURE.md`.
- **Local Development Guide**: See `docs/LOCAL_DEVELOPMENT.md`.
- **Deployment & Production Setup**: See `docs/DEPLOY.md`.
- **Roadmap & Requirements**: Review `docs/PLAN.md`.

## Questions and Discussions

If you have questions about how to use InkBoard, need architecture advice, or want to discuss feature ideas:
- Open a discussion in GitHub Discussions: https://github.com/ellaboevans/inkboard/discussions

## Reporting Bugs

If you find a reproducible bug in InkBoard:
- Search existing GitHub Issues to see if it has already been reported.
- If not, create a new issue using our Bug Report template.
