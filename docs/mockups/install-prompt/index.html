InkBoard · design round · not built

Install nudge

Telling readers and writers that InkBoard can live on their home screen or dock. Every frame uses the real board, toolbar, colours and type; only the card, the toolbar button and the menu item are new.

Phones

The card is part of the bottom overlay column, so it can never cover the zoom bar.

Desktop

The card hangs from the toolbar’s install button, top right: clear of the minimap and the zoom bar.

Always available

After “Not now”, installing stays one click away, and nothing shows once InkBoard is installed.

Choices made in this round

  • The card is a plain region, not a dialog: it doesn’t take focus or block the board, and sits in the same flow column as the zoom bar, so the two can’t overlap.
  • On iPhone the zoom bar stays and the card sits under it, so the card’s arrow has a clear line down to Share.
  • “Not now” hides the card for a while; “Got it” (Safari) hides it for good. The toolbar button and the menu item stay either way.
  • On phones the toolbar gets no install button: its icon buttons are 28 px and it’s at its two-row limit at 320 px. The browser’s own menu still offers it.
  • Touch buttons in the phone cards are 44 px high; all text meets 4.5:1 against its background.
